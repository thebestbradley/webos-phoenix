First Use runs when the phone starts for the first time. To go through
it again, and to see the gesture tutorial, open **Settings > Device
Info** and tap **Run setup again**. Every step can be skipped.

Nothing is erased. To start from scratch, use **Erase Apps & Data** in
Device Info.
