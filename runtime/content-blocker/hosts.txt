#
# Copyright (c) 2026 webOS Phoenix contributors
# SPDX-License-Identifier: Apache-2.0
#
# Written for Phoenix from the names of well-known advertising and tracking
# services (no other list was copied: the popular community lists are
# GPL or CC BY-SA, which Phoenix does not ship; docs/LEGAL.md). One host a
# line; a listed host blocks its subdomains too. Requests a page makes to
# these fail while Browser > Preferences > Block Ads & Trackers is on; a
# site on the list opened on purpose still loads (shell/sim/contentfilter.h).
#
# Keep it short and certain: only hosts that serve ads, ad measurement or
# cross-site tracking, never a CDN or a sign-in service a site needs.
