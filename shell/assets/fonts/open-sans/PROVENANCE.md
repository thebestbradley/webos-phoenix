# Provenance

Open Sans 1.11 by Steve Matteson, digitized data copyright (c) 2010-2011
Google Corporation, Apache-2.0. Copied unmodified from the Debian / Ubuntu
package `fonts-open-sans` 1.11-2 (upstream <https://www.opensans.com/>):
Regular, Bold, Light, Semibold, Italic and BoldItalic.

It stands in for Palm's Prelude, which is not redistributable: the shell
and the apps use Prelude when it is installed and Open Sans otherwise.
